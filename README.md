# LiveKit Final-Expense Voice Agent

A room-based voice-agent prototype with a deterministic qualification flow and optional SIP transfer to a licensed agent.

## Conversation flow

The agent collects an age and name, asks whether the caller is interested, and tracks whether a transfer was attempted, completed, or failed. Transfer can be enabled or disabled through configuration and requires a licensed-agent number.

The qualification flow is implemented in Python rather than generated by an LLM. Speech recognition uses Groq Whisper (`whisper-large-v3-turbo`), speech output uses Cartesia (`sonic-3`), and Silero VAD handles voice activity detection.

## Configuration

Install dependencies with `pip install -r requirements.txt`. Configure `GROQ_API_KEY` and `CARTESIA_API_KEY` locally. Optional settings include `AGENT_NAME`, `COMPANY_NAME`, `MIN_AGE`, `MAX_AGE`, `ENABLE_SIP_TRANSFER`, and `LICENSED_AGENT_NUMBER`. Keep credentials and phone numbers out of version control.

Run the LiveKit Agents worker in development mode:

```bash
python voice_agent.py dev
```

A LiveKit room and SIP participant are needed to exercise the call-transfer path. Transfer requires the setting to be enabled and a destination number to be configured.
